# NewtGrid website

Open `index.html` in a browser to preview the website.

## Before publishing
1. In `index.html`, find `const FORM_URLS={creator:"",brand:""};`
2. Paste your Creator Google Form URL and Brand Google Form URL into the matching quotes.
3. Upload the complete `newtgrid-website` folder to your web host.

The intro animation, responsive navigation, section links, phone/email links and scroll reveals are included. The supplied brand artwork is in `assets/`.
